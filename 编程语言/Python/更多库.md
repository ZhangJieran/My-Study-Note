## typing

### Annotated

附加元数据<br>

`MyVar:Annotated[指定类型,meta1,meta2...]`
<br>
MyVar 是指定类型，并且它附带有元数据


`MyVar.__origin__`&emsp;是MyVar的指定类型<br>
`MyVar.__metadata__`&emsp;是一个元组，里面储存元数据

<br>

### TypedDict

>[!CAUTION]字典加类型注解
>不检查，即使和注解类型不一样也不报错

```py
# 定义一个字典
class MyDict(TypedDict):
    name : str
    age  : int

a : MyDict = {"name":"jack","age":20}
```
a 就是一个字典，不是MyDict实例。
