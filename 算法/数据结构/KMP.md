next数组的语义：
不匹配时，下一个模式串用来匹配的字母的下标

如何求next数组？
1.先求PM（最长相同前后缀）
2.PM所有元素后移一位，并加1，最前面补0

e.g.
数组下标 1  2  3  4  5
模式串s  a  b  a  b  a  

PM       0  0  1  2  3

next     0  1  1  2  3

PM[3] = 1 因为ab   最长相同前后缀长度为0 
PM[3] = 1 因为aba  最长相同前后缀长度为1 
PM[4] = 2 因为abab 最长相同前后缀长度为1 
......


将PM转换成next
0  0  1  2  3     向后移
    |
    V
_  0  0  1  2  3   3溢出了，去掉，所有元素＋1，前面有空，补0
    |
    V
0  1  1  2  3
