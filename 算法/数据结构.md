<h2>堆</h2>

堆 = 完全二叉树
大根堆 = 父节点>=子节点 
小根堆 = 父节点<=子节点 

```
给完美二叉树每个节点编号
            0
        1        2
       3 4      5 6
       ......
      
下标映射到数组arr来存储这棵树
```

>[!IMPORTANT] 节点关系
>如果父节点下标为 i :
>左子节点：2i+1     
>右子节点：2i+2
>
>子节点下标 i :
>父节点 (i-1)/2

<br>

<h3>堆的基本操作</h3>

>[!NOTE]<strong>以下均以大根堆为例</strong>

<strong>下滤</strong><br>
时间复杂度 log_n

```
while 该元素<最大子元素:
    swap(该元素,最大子元素)
```

<strong>上滤</strong><br>
时间复杂度 log_n

```
while 该元素>父元素:
    swap(该元素,父元素)
```


<strong>堆插入新元素</strong>
时间复杂度 log_n

```
NewElem = arr[ len(arr)-1 ]   
上滤(NewElem)
```

<strong>建堆</strong>
通过乱序的数据建堆<br>
1.时间复杂度 nlog_n

```
2.时间复杂度 n

```
