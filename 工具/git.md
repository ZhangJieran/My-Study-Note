<h2>关联远程仓库</h2>

```
git remote add 远程仓库别名 origin https://...

查看当前关联的远程仓库
git remote -v
```

<br><br><br>

<h2>创建远程分支</h2>

```
git push -u 远程仓库名 本地分支
```
推送时创建一个远程分支并建立绑定关系


<br><br><br><br><br><br><br><br>

>[!NOTE] 新建仓库
>先在本地仓库随便提交点什么&emsp;   --->&emsp;创建本地仓库main分支<br>
>使用 git push -u 提交点什么&emsp;---->&emsp;创建远程仓库main分支
>
