## 抽象工厂

产品+工厂,用来生产一套配套的产品


```
工厂生产书和笔两种产品，书和笔有红蓝两套变种

# 两种产品的抽象类
class Pen: pass
class Book: pass
# 工厂的抽象类
class Factory:
    def create_book()
    def create_pen()


# 生产红色那套的逻辑
class RedPen: pass
class RedBook: pass
class RedFactory:
    def create_book()
    def create_pen()


# 生产蓝色那套的逻辑
class Bluepen: pass
calss BlueBook: pass

    def create_book()
```

## 建造者模式

分为生产组件和组装两步骤

- 要有地方存放配置信息
- 一个类负责设置配置信息
- 组装可以单开一个Director类负责，也可以让builder负责。
- Director可以承担特化的任务

```
# 用来保存笔记本配置信息
@dataclass
class LabtopConfig:
    GPU,
    CPU,
    screen

class LabtopBuilder:
    # 设置配置信息
    def config_GPU()
    def config_CPU()
    def config_screen()
    
    # 重置配置信息
    def reset()
    
    # 工厂函数,组装返回笔记本实例 
    def assemble()

# 一键生成
class Director:
    def CheapLabtop()
        reset()
        config_GPU()
        config_cPU("i5")
        config_screen("75HZ")
        assemble()
    
    def ExpensiveLabtop()
        reset()
        config_GPU("RTX 5090")
        config_cPU("i9")
        config_screen("144HZ")
        assemble()


```

<div id="observe">

一个状态变化，其它要跟着响应

```
class Observer:
    def update()

class Subject:
    def __init__()
        self.obsevers = []
    def attach()   # 订阅    
    def detach()   # 取消订阅
    
    #通知全部观察者
    def notify():
        for obs in self.obsevers:
        obs.update()
```
