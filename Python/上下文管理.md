<h3>try-except-finally</h3>

```
try:                          e.g.  |   try:
    ...                             |        ...
                                    |
except 异常对象:                     |  except KeyError as error : 
    ...                             |       print(error)

finally:                            
    ...
```
执行try。只要离开try，就一定会执行finally,哪怕try里报错了<br>
as拿到异常对象实例
